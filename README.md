# 🚀 DataBlocky

DataBlocky is a visual editor for Minecraft Java Edition datapacks. Build .mcfunction commands by connecting blocks instead of writing every command by hand.

## ✨ Features (What works right now)
- **Inline Inputs:** Clean horizontal layout that reads like actual Minecraft code.
- **Workspace Zoom:** Built-in canvas scaling with mouse wheel support for heavy data packs.

## 🛠️ How to run
- Install Node JS (downloads and instructions: https://nodejs.org/en/download/)
- git clone https://github.com/Romero-dev/DataBlocky.git
- cd DataBlocky
- npm install
- npm start
- Web page open automaticly or open browser on http://localhost:8080
